**Expense Tracker**

A simple and user-friendly Expense Tracker built with Python to record, store, and manage daily expenses.

✨ **Features**


➕ Add new expenses
📝 Store expense details
📋 View recorded expenses
💰 Calculate total expenses
💾 Save data using file handling
🔄 Read previously stored expense data
🧩 Uses functions for organized and reusable code


🛠️ **Technologies & Concepts**


Python
File Handling
Functions
Lists & Dictionaries
Loops
Conditional Statements
User Input
