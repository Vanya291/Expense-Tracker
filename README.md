**Expense Tracker**

A simple Python-based Expense Tracker to record, manage, and calculate daily expenses.


**Features**
Add expenses
Store expense details
Calculate total expenses
Save expenses in a text file
View all recorded expenses
**Technologies Used**
Python
File Handling
Exception Handling
Lists
Loops
Functions


**How to Run**
Download or clone this repository.
Open the project in VS Code.
Run expense_tracker.py.
Enter the expense name and amount.
The program will calculate the total expense.
